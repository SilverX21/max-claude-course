### Notable Decisions
- Used `bun:sqlite` (native Bun API) instead of `better-sqlite3`
- Unit tests use `bun test` runner (vitest incompatible with bun:sqlite)
- `mock.module()` from `bun:test` used to inject in-memory DB for tests
- E2E tests require `page.reload()` after sign-up to ensure RSC Header re-renders with session cookie
- Google Fonts removed from layout (sandbox network restriction)
